# ENTRE — Estudio de experiencia de servicio interno · V3

Demostración interactiva de una metodología de diagnóstico de servicios internos. Toda cifra y relación de este ejemplo es simulada. No se presenta información real de ISALUD.

## Qué incluye
- Estudio editorial y caso explicado desde la solicitud hasta el cierre.
- Matriz interactiva de 30 relaciones dirigidas entre seis áreas ficticias.
- Filtros por solicitante, prestadora y tres indicadores, con bases visibles.
- Priorización exploratoria por evaluaciones desfavorables estimadas.
- Blueprint del recorrido de un servicio.
- Metodología detallada: 4 fases, 16 actividades y productos verificables.
- Cuestionario de referencia de 8 preguntas, definiciones y tratamiento de datos.
- Plan de trabajo indicativo de 13 semanas, productos, seguimiento y resguardos.
- Diseño responsive, sin proceso de compilación.

## Uso
Abrir `index.html` en un navegador. Publicar como sitio estático en GitHub Pages, Vercel u otro hosting. El archivo `datos_simulados.csv` documenta las 30 relaciones. La web utiliza una copia incorporada de estos datos para funcionar de manera autónoma.

## Limitaciones
Las 1.211 observaciones son evaluaciones ficticias, no personas únicas. Los porcentajes de origen están redondeados y cualquier estimación derivada es aproximada. La regla de publicación por cantidad mínima de casos es un resguardo preliminar que debe validarse para cada organización.
